# CR-10 Smart Upgrade Notes

Research and implementation notes for upgrading a **Creality CR-10 Smart** (original mainboard: `CRC-2405V1.1`).

## Current target configuration

- Printer: Creality CR-10 Smart
- Original mainboard: `CRC-2405V1.1`
- Firmware: Klipper
- Toolhead: BIQU H2 V2S
- Bed probe: BIGTREETECH Eddy Duo
- Mainboard under consideration: BIGTREETECH Octopus Pro
- Stepper drivers: TMC2209
- System voltage: 24 V
